DESIGN SYSTEM — LANDING PAGE “O CORPO RESPONDE”

Crie uma Landing Page premium, moderna, responsiva e focada em conversão para a marca:

O CORPO RESPONDE
Serviço: Análise Corporal / Autoconhecimento

IMPORTANTE:
Este prompt define o Design System e a direção visual do projeto.
Mantenha consistência absoluta entre todas as seções e componentes criados.

==================================================
1. CONCEITO CENTRAL DA IDENTIDADE
==================================================

A identidade visual deve transmitir:

• Clareza
• Profundidade
• Autoconhecimento
• Confiança
• Acolhimento
• Autoridade
• Sofisticação
• Organização

Conceito visual central:

“Seu corpo é um mapa. Aprenda a compreendê-lo.”

A Landing Page deve comunicar visualmente que existem padrões por trás da maneira como uma pessoa pensa, sente, reage e se relaciona.

Utilize referências visuais sutis relacionadas a:

• mapas;
• trajetórias;
• linhas corporais;
• contornos humanos;
• conexões;
• caminhos;
• pontos de análise;
• padrões;
• movimento.

Esses elementos devem ser abstratos e sofisticados.

NÃO transformar a página em uma interface médica.

NÃO utilizar estética de hospital, consultório clínico ou laboratório.

NÃO utilizar estética genérica de psicologia baseada excessivamente em bege, folhas, pedras, flores ou elementos zen.

A marca deve ocupar um território visual intermediário entre:

AUTOCONHECIMENTO + ANÁLISE + PREMIUM.

==================================================
2. ESTILO VISUAL
==================================================

Direção:

Minimalismo editorial contemporâneo.

A página deve ter:

• bastante espaço negativo;
• seções amplas;
• títulos grandes;
• poucos elementos decorativos;
• forte hierarquia tipográfica;
• fotografia premium;
• contraste entre áreas claras e escuras;
• cards organizados;
• microinterações discretas;
• sensação de produto/serviço de alto valor.

Evitar aparência de template pronto.

Evitar aparência excessivamente “SaaS”.

Evitar excesso de gradientes.

Evitar glassmorphism exagerado.

Evitar excesso de sombras.

Evitar excesso de ícones.

Evitar elementos que pareçam gerados por IA.

18. ELEMENTO GRÁFICO DA MARCA
==================================================

“SEU CORPO É UM MAPA.”

Utilizar linhas abstratas inspiradas em:

• mapas topográficos;
• contornos humanos;
• caminhos;
• conexões;
• trajetórias.

Utilizar:

#42B4A3

5–12% de opacidade.

NÃO parecer ilustração anatômica.

NÃO parecer mapa geográfico literal.

NÃO parecer interface tecnológica futurista.

• olhando para câmera;
• sentado;
• em pé;

• postura natural.

• poses exageradas;
• sorriso artificial;
• estética de médico;
• jaleco;
• estetoscópio;
• ambientes hospitalares;
• fotografias genéricas de banco de imagens.

Fotografias conceituais podem mostrar:

• postura corporal;
• movimento;
• pessoas refletindo;
• interação humana;
• detalhes de mãos;
• silhuetas;
• diferentes posições corporais.

Direção:

==================================================
23. MICROINTERAÇÕES
==================================================

Utilizar animações suaves.

Duração:

150–350ms.

Permitido:

• fade;
• translateY discreto;
• hover em cards;
• mudança suave de border;
• pequenos movimentos das linhas gráficas;
• transições do calendário;
• accordion suave;
• indicadores de progresso.

Evitar:

• parallax exagerado;
• elementos pulando;
• animações infinitas chamativas;
• textos entrando de todas as direções;
• efeitos 3D desnecessários.

A animação deve transmitir refinamento, não espetáculo.

==================================================
24. RESPONSIVIDADE
==================================================

Mobile-first.

No mobile:

• H1 menor;
• cards em uma coluna;
• CTAs largos;
• botões com área de toque mínima de 48px;
• textos confortáveis;
• calendário totalmente utilizável;
• barra fixa de conversão;
• imagens reposicionadas;
• elementos gráficos simplificados.

Evitar simplesmente reduzir a versão desktop.

A experiência mobile deve ser projetada especificamente.

==================================================
25. ACESSIBILIDADE
==================================================

Manter contraste adequado.

Nunca usar turquesa claro para textos pequenos sobre branco.

Inputs devem possuir label.

Botões devem possuir estados:

default;
hover;
focus;
active;
disabled.

Elementos clicáveis:

mínimo 44–48px.

Adicionar focus-visible.

Utilizar HTML semântico.

Respeitar prefers-reduced-motion.

==================================================
26. EXPERIÊNCIA DE CONVERSÃO
==================================================

Toda a página deve conduzir naturalmente para:

AGENDAR UMA ANÁLISE.

Não colocar CTA em absolutamente todas as seções.

Utilizar CTAs estrategicamente após momentos importantes de convencimento.

O usuário deve entender rapidamente:

1. O que é oferecido.
2. Para quem é.
3. O que pode descobrir.
4. Como funciona.
5. Quem realiza.
6. Por que confiar.
7. Como agendar.
8. Como tirar dúvidas.

Sempre que houver duas opções:

AGENDAR deve ter prioridade.

WHATSAPP deve ser suporte.

“Isso parece profissional.”

“Não parece uma terapia genérica.”

“Quero descobrir como eu funciono.”

“É fácil marcar meu atendimento.”
